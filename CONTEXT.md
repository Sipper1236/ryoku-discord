# Theme palette

This context names the color sources and modes used by the Ryoku Discord theme.

## Language

**Ryoku palette**:
The theme's original red and gold colors. This is the fallback when the Vesktop bridge integration is disabled.

**Live palette**:
The current colors supplied by Ryoku Palette Bridge to Vesktop/Vencord while Discord remains open.

**Palette mode**:
The color source controlled by Super+W → Ryoku Palette Bridge → Vesktop (with an advanced CSS override): the Ryoku palette or the live palette. Live mode falls back to the Ryoku palette when bridge colors are unavailable.

**Status colors**:
Colors that communicate Discord presence states such as online, do not disturb, idle, and streaming. In live mode, each state follows its corresponding bridge palette role.
